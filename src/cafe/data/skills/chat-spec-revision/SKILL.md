# Chat Spec Revision

## Use This Skill When
- The user and agent determine the requirements or specification need to change.
- The spec may be revised directly in chat or the chat may only establish what must change.

## Instructions
- Make it explicit whether the spec was already updated during chat.
- Summarize the revised requirement in concrete terms.
- If the spec was not updated yet, say that follow-up work is still needed.
- Finish with the required common chat handoff format.
