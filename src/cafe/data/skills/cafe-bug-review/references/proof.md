# Defect evidence gates

[ ] Read required diagnosis, repair summary and verified workspace; record baseline/HEAD and regression identity.
[ ] Independently verify the RED defect cause and unchanged-regression GREEN evidence, expected behavior authority and focused checks.
[ ] Assess repair correctness and minimal scope without editing the code; workspace records cannot replace regression proof.
[ ] Identify ordinary repair findings versus invalidated diagnosis and select the declared correction route with causal Todo closure/evidence.
[ ] Preserve valid prior evidence and original scope; every PR-requested code correction must receive independent review.
[ ] Apply the shared three-round disagreement rule and existing clarification/permission/iteration-limit boundaries.
[ ] Write a non-empty independent assessment and legal handoff only when all applicable evidence gates are resolved.
