# Defect evidence gates

[ ] Read required diagnosis and verified workspace; preserve confirmed scope and expected behavior.
[ ] Install the exact retained regression and reproduce defect-specific RED before changing production behavior.
[ ] Apply a minimal repair, obtain unchanged-assertion GREEN and record relevant focused checks.
[ ] Retain unfixed revision/test identity, RED/GREEN commands and actual statuses, diff scope, commits and current evidence in a self-contained summary.
[ ] Commit regression and fix with normal hooks, leaving a clean worktree including untracked files.
[ ] Invalidate only unsupported evidence and request renewed diagnosis proof when necessary; retain unrelated valid evidence.
[ ] Resolve applicable causal Todo items with canonical IDs and verified evidence; every successful code batch enters independent review.
[ ] Apply the shared three-round disagreement rule and existing clarification/permission/iteration-limit boundaries.
