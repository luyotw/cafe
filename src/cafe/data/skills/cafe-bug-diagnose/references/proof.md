# Defect evidence gates

[ ] Read the confirmed defect request, expected behavior authority and available prior evidence.
[ ] Record reproduction trigger, environment, command, expected and observed behavior, cause and uncertainty.
[ ] Demonstrate defect-specific RED regression on an identified unfixed revision; setup/dependency/unrelated failures and disputed behavior remain inconclusive.
[ ] Retain replayable test source/patch, exact test identity, actual exit status and bounded failure evidence.
[ ] Keep proposed repair scope minimal and hand off a clean active workspace; do not commit a failing test through bypassed hooks.
[ ] Persist original decisions, unresolved work and evidence; on interruption or changed revision/assertion revalidate before claiming completion.
[ ] Complete applicable causal Todo evidence and summary before a legal handoff; unresolved diagnosis enters existing clarification or permission.
