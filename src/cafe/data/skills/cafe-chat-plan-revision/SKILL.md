# Chat Plan Revision

## Use This Skill When
- The implementation plan, sequencing, or technical approach changes during chat.
- The plan may be updated directly in chat or the chat may only define the new direction.

## Instructions
- State whether the plan was already updated during chat.
- Summarize the revised plan or technical direction.
- If the plan was not updated yet, say that follow-up work is still needed.
- Finish with the required common chat handoff format.
