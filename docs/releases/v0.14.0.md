# CAFE v0.14.0 release notes and upgrade guide

## Dashboard workflow status

CAFE publishes the workflow status, current phase, phase iteration, and pending
task count to a paired CAFE Dashboard connector. The Dashboard can display a
running workflow before it has a pending task. Archived summaries provide a
history after the source checkout is removed. Phase iterations reflect started
work and omit preparations that have yet to run.

Use the normal Dashboard pairing flow with a Dashboard and connector version
that supports workflow phase iterations.

## Reviewed local delivery

The `standard` playbook can prepare a reviewed Git integration for a local
target checkout. Approve the displayed diff to bind the integration to the
reviewed source and destination. When the accepted closeout selects cleanup,
`cafe close` verifies the integration receipt and checkout identities before
removing the source. Cleanup can preserve verified archive evidence across
volumes and continue from the saved record after interruption.

## Upgrading an active workflow

Upgrade CAFE through the installation method you already use. For a `uv tool`
installation, run `uv tool upgrade cafe-engine` and check `cafe version`.
Keep the issue worktree, `.cafe` records, and any retained closeout archive
through the upgrade. Continue from the current task or handoff so CAFE can
validate its saved evidence. A retry of an interrupted step can start a fresh
session once CAFE verifies the saved interruption and confirms that session
identity is unavailable or that the provider was never invoked.
