# CAFE v0.13.0 release notes

## CAFE Dashboard compatibility

The separate CAFE Dashboard application can inspect versioned HumanTask inputs,
save supported Plan review and clarification replies, and request continuation
of the exact saved result through the CAFE CLI.

`cafe task inspect <task-id> --json` exposes the current input snapshot. A client
submits its reviewed `snapshot_version` with `cafe task complete`. CAFE validates
the task, input, and handoff at completion and retains the accepted review
evidence. A changed snapshot requires the client to inspect and review it again.

`cafe task continuation` observes or resumes a saved result using its task,
issue, workflow, and result identifiers. Recovery and repeated requests reuse
the saved decision. Continuation holds the workflow advancement and handoff
leases so a competing handoff update cannot consume the wrong result.

Capability approvals and other specialized tasks retain their existing CLI
protocols. Dashboard presents its supported forms according to the available
snapshot and native task contract.

## Closeout cost reporting

Codex App Manager cost reports can include verified callback turns, explicitly
selected direct conversation turns, and native subagent usage. The report
refreshes expired pricing and retains known subtotals when evidence is
incomplete. Reconstructed usage and selected turns are scoped to the report.
