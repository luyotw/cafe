# CAFE v0.12.3 release notes

## Manager closeout

Manager closeout accepts the full issue identifier, such as `team/fix-login`,
and locates the issue in its owning worktree. Closeout evidence remains bound
to the exact issue and workflow.

## Workflow recovery

CAFE retires worker records when the recorded boot or process evidence confirms
the worker has stopped. A resumed step can reuse the session recorded before the
interruption. When the provider rejects that session as unavailable, an eligible
workflow resume can continue the same step with the same CLI and model in a
fresh session, using the saved artifacts, checklist, and worktree.
